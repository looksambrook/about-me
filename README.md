# About Me

온디바이스 AI 개발자를 목표로 하는 박채빈의 자기소개 페이지입니다.
바닐라 HTML과 CSS만 사용해 로컬 NPU, 실시간 처리, 기기 내 데이터 처리 콘셉트를 시스템 HUD 형태로 표현했습니다.


## 주요 내용

- 모바일 앱 개발을 중심으로 공부한 경험
- 3학년 딥러닝 연구 및 논문 작성 경험
- 4학년 시스템 분석 인턴 경험
- 온디바이스 AI 개발자라는 목표
- 데스크톱과 모바일을 지원하는 반응형 UI

## 사용 기술

- HTML5
- CSS3
- CSS Grid 및 Flexbox
- Responsive Web Design

## 실행 방법

`index.html`을 브라우저에서 열면 확인할 수 있습니다.

```text
about-me/
├── index.html
├── style.css
├── image.png
├── image-1.png
└── README.md
```
