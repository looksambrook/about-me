# About Me

온디바이스 AI 개발자를 목표로 하는 박채빈의 자기소개 페이지입니다.
바닐라 HTML과 CSS만 사용해 로컬 NPU, 실시간 처리, 기기 내 데이터 처리 콘셉트를 시스템 HUD 형태로 표현했습니다.


## 주요 내용

- 모바일 앱 개발 전공
- 3학년 딥러닝 연구 및 논문 작성 
- 4학년 시스템 진단 인턴 
- 꿈: 온디바이스 AI 개발자

## About Me에 사용된 기술(feat. Codex)
- HTML5
- CSS3
- CSS Grid 및 Flexbox
- Responsive Web Design

## 실행 방법

`index.html`을 브라우저에서 열면 확인할 수 있습니다.

```text
about-me/
├── index.html
├── style.css
├── image.png
├── image-1.png
└── README.md
```
